Privacy

Last updated: 23 October 2026

TaskFlow is a local-first app. Tasks, projects, goals, reviews, and settings are stored in this browser (localStorage). There is no TaskFlow account and no TaskFlow server that stores your work.

What stays on this device

  • Tasks, projects, goals, weekly reviews, progress, and theme
  • Trial flags and a redeemed license key
  • An optional AI API key you type in Settings (never uploaded to TaskFlow)

What can leave this origin

  • Checkout: paying opens the seller’s payment provider (Stripe, Razorpay, or similar). That provider sees whatever their checkout collects.
  • Optional LLM: if you save a key and click Plan with AI, the prompt is sent to the endpoint you configured. TaskFlow does not proxy it.
  • Fonts: the app prefers system fonts. If a host still loads a webfont, that request leaves the origin.

No sale of task data

We do not run ads, do not sell task content, and do not upload the conversion funnel. Funnel events stay in this browser.

Cookies and tracking

TaskFlow does not set advertising cookies. localStorage is used for the app itself.

Your rights

Export JSON or CSV from Settings. Erase all data from Settings. Clearing this site’s storage in the browser also deletes the local copy. There is no TaskFlow account to request deletion from.

Questions: use the support email in Settings if the seller configured one, or the email on your payment receipt.
